\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Stitch proposes a social augmented-reality interface in which digital posts are associated with
physical places and recovered when a later visitor observes the same scene. Its original
implementation matches SIFT features to one reference image and projects content using a planar
homography. This thesis investigates whether pretrained representations improve recognition and
anchoring under appearance change while retaining a reproducible path toward mobile deployment.

A modular implementation compares SIFT with FLANN, SuperPoint with LightGlue, CosPlace global
retrieval, and a hierarchical combination of retrieval, local matching, geometric verification,
and rendering. Experiments use a documented HPatches subset, a custom cross-time subset of real
Tokyo 24/7 query photographs, and seeded photometric transformations of repository and benchmark
images. Original scripts are executed through a bounded file-input adapter. All reported
measurements, plots and tables are derived from preserved run outputs.

The evaluation distinguishes retrieval, geometric acceptance and ground-truth homography accuracy.
Tokyo metadata supports place labels but does not establish metric camera pose or planar anchoring
error. Short contrastive adaptation trains only a projection head on disjoint HPatches places.
Model export and integer quantisation are tested using actual ONNX inference. The report documents
accuracy losses, rejected anchors, and the limits of narrow galleries and synthetic illumination changes.

The resulting artifact demonstrates a reproducible planar-AR research pipeline. It does not
establish a city-scale AR cloud, a six-degree-of-freedom localisation benchmark result, or phone-device
performance. The deployment analysis specifies the mapping, calibration, tracking, privacy and
evaluation work needed before persistent public AR content can be supported responsibly.
