\section{Provenance chain}
Image bytes are identified in the data manifest. Generated query bytes and their seeds are identified in preparation records. Model bytes and official implementation revisions are identified in the model manifest. The evaluation configuration pins the benchmark manifest hash. Raw pair and prediction rows support generated statistics, and \code{artifact_provenance.json} records the result-file hashes consumed by figure/table generation.

This chain separates input provenance from output interpretation. A filename or hash does not prove that a public label is correct, but it makes the precise source of a reported outcome inspectable. A future extension should preserve that distinction when adding metric maps or a service-side database.
